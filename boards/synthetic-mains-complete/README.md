# Synthetic mains-style fixture for `--complete` creepage verification (#8422)

Fully synthetic and public-safe: generated by `generate_fixture.py` with no inputs,
not derived from any real or side-project design.

- `mains_fixture.kicad_pcb`: 2-layer 70x52 mm board. Three mains footprints (`/LINE`,
  `/FUSED_LINE`, `/NEUT`, 150 V class) form a column "wall"; adjacent footprints' pads
  are 2.42 mm apart, so a trace squeezed between them gets ~1.1 mm to each side against
  the 1.6 mm class (IEC 60664-1, PD2, IIIa). Low-voltage links (`/SENSE_A..D`, `GND`)
  between parts either side of the wall take the short path through those gaps unless
  creepage stops them.
- `voltage_map.json`, `net_class_map.json`: the maps passed to both `kct route` and
  `kct creepage`.
- `negotiated_stage.kicad_pcb`: output of the negotiated stage (HV nets + `/SENSE_D`),
  checked in so the regression test (`tests/test_route_complete_creepage_fixture_8422.py`)
  only has to run `--complete`.

## Recipe

```bash
HV="--net-class-map net_class_map.json --voltage-map voltage_map.json \
    --creepage-standard iec60664 --pollution-degree 2 --material-group IIIa \
    --hv-threshold 0 --skip-drc --no-auto-pour"
kct route mains_fixture.kicad_pcb -o neg.kicad_pcb $HV --nets /LINE,/FUSED_LINE,/NEUT,/SENSE_D
kct route neg.kicad_pcb -o comp.kicad_pcb $HV --complete --complete-report report.json
kct creepage <pcb> --net-class-map net_class_map.json --voltage-map voltage_map.json \
    --standard iec60664 --pollution-degree 2 --material-group IIIa \
    --waive-same-footprint --waive-attach-zone
```

## Recorded run

Tools: kicad-tools 0.28.0 at `995b75b9d`, Python 3.12.3, C++ router backend built,
linux x86_64, 2026-11-07.

| board | creepage pairs | failing | min creepage (mm) |
|---|---:|---:|---:|
| `mains_fixture` (input) | 22 | 0 | 2.42 |
| after negotiated route | 21 | 0 | 2.00 |
| after `--complete`, **rollback disabled** (counterfactual) | 21 | **6** | **0.253** |
| after `--complete`, as shipped | 21 | **0** | 2.00 |

With the rollback disabled the lattice completion commits 6 failing pairs (e.g.
`/FUSED_LINE`-`GND` 0.253 mm, `/LINE`-`/SENSE_C` 0.300 mm, `/FUSED_LINE`-`/SENSE_B`
0.720 mm, all against 1.6 mm). As shipped, `--complete` rolls back all 5 links that would
have added them (`reason: creepage-rolled-back`, listed in `--complete-report` with
blocking net, required and measured mm) and leaves 0 new failures.

This is harder than #8403's test: that test hand-places one segment on a stub router;
this runs the real negotiated route then the real `--complete` over multiple nets and
both layers, with the census as referee.

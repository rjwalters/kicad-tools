- **`kct check --mfr jlcpcb*` can newly fail on `mask_to_copper`** (Issue #9234). Boards carrying a keepout rule area (the stock RF-module footprint shape) used to stop at `assessment incomplete`, with findings capped at warning, because the footprint-embedded rule area was inventoried as a required native object the per-object worker never found; the assessment now completes on those boards, so its findings report at their real severity. The reporting board measured 570 info / 513 warning on main `d07828e5e` and 570 info / 489 error / 24 warning with the fix; a run that exited `0` under `--allow-incomplete` can now exit `2`. No threshold or severity rule changed.

- **`kct pcb reinforce --strategy parallel` record-less re-runs no longer
  accrete the end-tie vias of SMD-ended legs** (Issue #8970). `end_tie`'s
  adoption test was anchored at the leg vertex, which an SMD tie never
  matches -- the via sits one `min_clearance` past its reach -- so each
  re-run planted a fresh pair beside the pair already there (bounded at
  +4 vias per leg, reached on the fourth pass). An unowned, size-matched,
  same-net through via at the re-derived tie arc is now adopted in place,
  credited to `existing_vias` but recorded nowhere, so `--clear` still
  cannot remove copper the tool did not place.
  The same arc-frame fix also moves the **first-pass** far-end tie on
  cornered SMD-ended legs, which previously landed on the wrong point of
  the leg and overlapped the far pad (Issue #8996 pins it with a test).

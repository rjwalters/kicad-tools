- **`kct readiness` honours an `exception` known issue's exact error identities** (Issue #7355). An
  `exception` entry may carry `errors: ["rule@x/y", ...]` (`--known-issue N:summary:exception:!rule@x/y,...`),
  each the rule id plus the violation's location in mm rounded to 0.01 and cited to the issue, never a bare
  count. The `kct_check` gate passes only when the report's errors match those identities as a set: an
  unlisted or repeated error, an error with no location, or a listed identity that no longer fires still
  blocks. `defect` and `advisory` entries reject `errors`; the site validator mirrors the format.

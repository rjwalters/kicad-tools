- **`kct readiness` honours an `exception` known issue's exact `errors` allowance** (Issue #7355). An
  `exception` entry may carry `errors: {rule: count}` (`--known-issue N:summary:exception:!rule=count,...`);
  the `kct_check` gate passes only when the report's errors match it exactly, so any extra error, unnamed
  rule or different count still blocks. `defect` and `advisory` entries reject `errors`.

- **`kct check --mfr jlcpcb` no longer passes a board JLCPCB's DFM fails** (Issue #8938). `physical_copper_gap` no longer downgrades a same-net gap to a warning: a gap below the fab's danger edge is an error, labelled `same_net` in the text output and `--format json` so the class can be waived deliberately via `.kct_waivers.json`. The fab-view danger/warning bands now come from the resolved stackup's DFM threshold table instead of hardcoded 0.10/0.15 mm constants; a stackup with no recorded `warning_mm` has no warning band, and zone-fill (pour) gaps — which JLCDFM does not judge — report at info instead of warning.

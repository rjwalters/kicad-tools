- **`kct creepage` measures cross-face surface paths through non-plated bores,
  milled slots and the board outline** (Issue #9704). The census paired
  conductors per copper layer, so a path crossing from one board face to the
  other -- down the wall of an NPTH / mounting hole or a milled slot, or around
  the board edge -- was never measured: an HV run on B.Cu and another net's
  track on F.Cu could sit 3.75 mm of surface path apart through a bore while
  the report showed no row at all. Each rim now contributes
  `conductor-on-face-A -> rim` + board thickness + `rim -> conductor-on-face-B`
  as a candidate minimum, so a result can only get stricter, never looser; the
  binding row names the bore/slot/edge in a new `via_bore` field. Board
  thickness comes from the stackup strata sum when the file declares one, else
  a reported 1.6 mm default.

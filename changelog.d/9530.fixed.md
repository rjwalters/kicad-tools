- **Recovery mirror now y-mirrors custom-pad primitives** (Issue #9530).
  `StrategyApplicator`'s mirror strategy negated pad position/rotation/layers
  but left a custom pad's `(primitives ...)` untouched, so for an asymmetric
  custom pad the saved file and `custom_pad_copper` described different copper
  than KiCad's own left/right `Flip`. The primitives' local `y` is now negated
  (reusing the #8581 helper), pinned by an asymmetric custom pad in the
  `mirror_flip` golden pair.

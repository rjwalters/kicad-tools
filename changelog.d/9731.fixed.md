- **`kct pcb reinforce` mask-opening refusals report the minimum gap over the run** (Issue #9731). `RefusedOpening.actual_mm` (and the `mask_reason` text, the CLI line and the JSON `refused_openings` entry) carried the first failing sample's gap along the exposed run, so a blocker crossing the strip read as a near-miss ("6.208 mm, need 6.300 mm") when the true clearance was 0.000 mm. The refusal now reports the minimum gap to the chosen blocker over all samples of the run; which obstacle is named and its location are unchanged.

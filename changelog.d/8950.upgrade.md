- **`kct check` can newly fail on width-swap boards that passed silently**
  (Issue #8950). `path_ampacity` now reports the shared via of two doubled
  stretches whose width split swaps across it as an under-capacity layer
  change (previously it was skipped as if it were a benign stitching via). If
  your board has such a via, widen the copper so the split does not swap, or
  add same-net vias so the barrels' summed capacity covers the path's
  declared current (what `kct pcb reinforce --strategy parallel --current-paths`
  now does automatically at an SMD end).

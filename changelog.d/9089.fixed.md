- **Bulk `Test` CI job stops OOM-killing pytest-xdist workers** (Issue
  #9089). Native router / coupled-search replays leaked nanobind wrappers
  into cyclic garbage that the automatic GC did not reclaim between tests,
  so a worker's RSS ratcheted toward multi-GB across the bulk suite
  (measured: 4.4 GB after one 37-test Board07 replay file) until the runner
  killed it mid-test. Test sessions now run a full `gc.collect()` plus
  glibc `malloc_trim(0)` after any test that grew RSS by 32 MB or more,
  bounding the same file at a ~530 MB peak. Linux-only; no-op elsewhere.

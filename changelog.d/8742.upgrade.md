- **`kct pcb reinforce` default changed from a spaced anchor row to two end
  anchors per wire leg** (Issue #8742). Re-running it on a board places 2
  anchors per leg instead of one every 15 mm. To keep the old placement pass
  `--anchor-mode spaced` (and `anchor_mode="spaced"` to `reinforce_net`);
  `--spacing` now only applies there and is ignored, with a warning, in the
  default mode. Anchors from an earlier spaced run are not removed (#8747).

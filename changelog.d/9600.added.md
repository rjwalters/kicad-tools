- **`kct route` and `kct route-auto` report necked copper** (Issue #9600).
  Nets whose emitted copper narrows below their class width (pad-adjacent
  neck-down, escape stubs, the orchestrator's board-default-width
  corridors) are now summarised in the Results section with the narrowest
  width, necked length and longest contiguous run; runs longer than the
  neck-down taper distance are marked "long, verify intent". The
  ``--format json`` documents of both commands carry the same census as a
  ``necked_copper`` list (absent when no net is necked). The class width
  is each net's authored ``.kicad_pro`` netclass assignment first (a
  ``Wide`` 0.6 mm class wins over name heuristics and the board default),
  then the net-class map, then the global rule. Contiguous runs are
  measured from the copper geometry -- endpoint orientation, route
  boundaries and via-joined layer changes do not split a run, and copper
  on another layer without a via never joins one. Previously a run
  with several-mm necks reported plain "ok" (#9592 audit row 3).

- **`kct route --complete` deadline reporting is now honest per link** (Issue #9581). A `--complete` run with `--timeout` prints its budget derivation (`--timeout` minus setup, auto-fix and post-route reserves) at the start; per-link `deadline_hit` is true only for links the deadline kept out of the best pass (`reason: deadline-exceeded` now means never reached in any negotiation pass — a link an earlier pass declined on its own merits keeps that real decline reason), a new per-link `attempted` key marks links the search reached in any pass, per-link `elapsed_s`/`budget_s` are `null` (run totals stay at report level), the human-readable report says when a link was not attempted before the deadline, and progress output is line-flushed when stdout is redirected.

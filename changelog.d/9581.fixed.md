- **`kct route --complete` deadline reporting is now honest per link** (Issue #9581). A `--complete` run with `--timeout` prints its budget derivation (`--timeout` minus setup, auto-fix and post-route reserves, fractional precision preserved) at the start; per-link `deadline_hit` is true only for links the deadline kept out of the best pass (`reason: deadline-exceeded` means the deadline cut the pass before the link was re-reached — a link an earlier pass declined on its own merits keeps that real decline reason, and a link an earlier pass routed can still carry the stamp with `attempted: true`), a new per-link `attempted` key marks links the search reached in any pass (including each searched leg of an uncoupled diff-pair fallback, whose latest per-leg decline also survives a later pass the deadline truncates before the pair is revisited), per-link `elapsed_s`/`budget_s` are `null` (run totals stay at report level), the human-readable report says when a link was not attempted before the deadline, and progress output is line-flushed when stdout is redirected.

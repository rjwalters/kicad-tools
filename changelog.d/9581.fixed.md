- **`kct route --complete` deadline reporting is now honest per link** (Issue #9581). A `--complete` run with `--timeout` prints its budget derivation (`--timeout` minus auto-fix and post-route reserves) at the start; per-link `deadline_hit` is true only for links never reached (`reason: deadline-exceeded`) instead of inheriting the run-level flag, a new per-link `attempted` key marks the complement, per-link `elapsed_s`/`budget_s` are `null` (run totals stay at report level), the human-readable report says when a link was not attempted before the deadline, and progress output is line-flushed when stdout is redirected.

- **`route-auto` selects its grid automatically by default** (Issue #9620). The grid was fixed at clearance/2 with no memory cap and no override; it is now chosen by the same pad-aware, memory-capped selector as `kct route --grid auto`. Pass `--grid <mm>` (e.g. `--grid 0.1`) to pin an explicit pitch, or pass the board's clearance/2 to restore the legacy lattice exactly.

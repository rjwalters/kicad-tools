- **`kct check` has a new default-on `model_coverage` category** (Issue #7682). A footprint with no model ref (`no_ref`), or one whose model is missing from an installed library (`dangling`, placeholder, hidden-only), gets one advisory warning per footprint, so `kct check --strict` can newly fail; use `--skip model_coverage` to opt out. When the 3D model library itself is absent (its `${KICADn_3DMODEL_DIR}` is undefined or names a missing directory, as on CI and in the pinned toolchain image), the category reports one `info` finding ("3D coverage not evaluated ... see #7683") instead of a warning per footprint. Board manufacturing gates, readiness and bundle producers, the route lint gate, `run_drc` over MCP, `kct fix-drc`, benchmark metrics and export preflight deselect `model_coverage` until a pinned model set lands (#7683/#7685), so their verdicts and recorded evidence are unchanged. `kct render` now reports `partial` (exit code unchanged) for boards with bare footprints.

- **`kct drc --format json` gains `schematic_parity_checked`** (Issue #7077).
  Scripts that gate on `kct drc` should read this field: `false` means
  kicad-cli did not compare the board against the schematic, so a clean
  result says nothing about board/schematic agreement. The exit code is
  unchanged (a board with no schematic is still a normal case). The field is
  omitted when `kct drc` reads an existing `.json`/`.rpt` report.

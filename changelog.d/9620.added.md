- **`kct route` retries a budget-only failed batch once on a coarser grid** (Issue #9620). When a batch ends partial, the grid was auto-selected and every open net's recorded search failure is budget-labelled (per-net timeout / iteration cap), the run now re-routes the whole batch once at 2x the resolution, capped at the clearance safety ceiling, and promotes the retry's board only when it routes more nets; the log names the retry and the grid used. A zero-routed batch (exit 1) whose saved board shows every attempted net budget-exhausted retries the same way. Any geometric (no-path) failure, an explicit `--grid`, a non-failure exit, or a non-improving retry keeps the first result unchanged. The retry runs under `--format json` as well: stdout keeps exactly one JSON document, describing the selected board.

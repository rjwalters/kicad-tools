- **Routed-DRC identity gate refuses an incomplete pass instead of reading it as stale** (Issue #9706). `scripts/ci/check_routed_drc.py` (and the vendored copy, Epic #4054) now detects `<rule>_incomplete` records for any rule with `identity_allowances:` entries and fails with an explicit "`<rule>` did not run: native KiCad toolchain required" error, emitting no stale-allowance text for that rule. Previously a run without the qualified native toolchain (no kicad-cli, unqualified version, no `KCT_KICAD_DOCKER`) produced an info `mask_to_copper_incomplete` record with zero findings, which the gate mis-read as every allowance entry being stale and told authors to delete healthy entries. `IdentityOutcome` grows a fifth `incomplete` field (with a default, so positional constructions keep working); stale detection for rules that did complete is unchanged. The repo's own `routed-pcb-drc-check` CI job also sets `KCT_KICAD_DOCKER: "1"` on its ordinary step so `mask_to_copper` runs to completion on the pinned KiCad image there.

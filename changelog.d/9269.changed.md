- **`mask_to_copper` findings print the deciding beside-pad excess**
  (Issue #9269). When a finding's message reports `beyond owner pad copper`,
  it now also prints `beside owner excess <v> mm²` whenever that value was
  measured, so a reader can see why a `within_own_pad` info finding with a
  non-zero "beyond" copper is excused. Messages for measurements where the
  value was not evaluated are unchanged.

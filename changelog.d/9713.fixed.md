- **`kct check --fab-dfm-result` counts arc clearance findings** (Issue #9713).
  The four `clearance_arc_*` pair ids added by #9673 were attributed to no
  fab DFM parity row, so arc clearance errors under-counted both spacing
  categories. `clearance_arc_arc`, `clearance_arc_segment` and
  `clearance_arc_via` now count toward `trace_spacing`, and
  `clearance_arc_pad` toward `pad_spacing`; the parity table version moves
  with the content.

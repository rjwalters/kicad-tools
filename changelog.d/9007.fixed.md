- **Board 06's escape-via seats honour the same-net trace band** (Issue
  #9007). The pour-repair grid escape's `via_ok` seat predicate in
  `boards/06-diffpair-test/generate_design.py` graded only the same-net SMD
  pad family, so an escape through-via could seat in the (0, 0.1016) mm
  fab-view slit band of pre-existing same-net segment copper — the exact
  grading `_via_ok` already enforced for repair vias (#8975). All three
  band families (segment, via-annulus, SMD pad) now live in one
  diameter-parameterised helper called by both sites with the via's own
  annulus diameter, so the two can no longer drift apart.

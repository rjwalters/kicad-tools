- **`path_ampacity` / `current-paths-audit` flag a high-current path that changes layer through an undersized via** (Issue #8745, slice 4a of #8741). `PathResolution` now carries an ordered `layer_changes` record (via positions, drill, pad diameter, parallel-via count) and `kct pcb current-paths-audit` prints it (text and JSON). A layer change whose summed via-barrel capacity (IPC-2221 external formula on a 20 um plating annulus (IPC-6012 Class 2 average), 10 C rise) is below the path's design current is an error for `reinforcement_eligible` paths and a warning otherwise; waive it in `.kct_waivers.json` like any other `path_ampacity` finding.

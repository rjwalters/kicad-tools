- **`mask_to_copper` binding hashes changed with the portable command recording** (Issue #9055). `MaskSourceBinding.export_profile_sha256` now hashes the normalised (host-independent) native command instead of the raw host argv, so any committed `kct.mask-copper-request.v1` escape intent bound to a pre-#9055 hash no longer matches and must be re-pinned against freshly produced evidence.

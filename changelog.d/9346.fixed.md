- **`kct readiness --verify` no longer fails open when the CPL rotation re-derivation cannot run** (Issue #9346). A parse or read failure of the retained CPL/BOM/PCB, or any unexpected error, is now reported as a verification problem and recorded as `cpl_rotations.rederivation_skipped` in `readiness.json` instead of silently passing; the re-derivation also resolves the same effective PnP config as the export (`--include-tht`), so the checked placement set always matches the shipped CPL.

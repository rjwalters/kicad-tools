- **`kct check` no longer false-fails parallel-copy tie rows on widened clearance rule
  sets** (Issue #8992). The packed tie-row grouping behind `path_ampacity` derived its
  gap bound from a standalone constant (crossing at `min_clearance_mm ≈ 0.485` mm), so a
  rule set with wider clearance — ordinary for mains/HV hand-authored `DesignRules` — got
  its tie rows placed by `kct pcb reinforce --strategy parallel` and then judged via one
  via each ("through 1 via(s) … 1.60A below 15A"). `PathAmpacityRule` now threads the
  board's `DesignRules` into `audit_current_paths`/`resolve_current_path` (new optional
  `design_rules` parameter), and the grouping bound is computed from the same same-net
  via spacing rule the placer uses, capped at half the 5.0 mm distributed-stitch pitch.
  Rules-free callers of `resolve_current_path` keep the previous constant bound.

- **`silk_over_copper` no longer flags silk over the far side of a blind/buried via** (Issue #9116). An untented via's mask aperture is now yielded only for the outer sides the via actually reaches — the same `_via_silk_sides` definition `silk_hole_overlap` has used since #9104 — and a buried via contributes no aperture. Committed boards are unaffected: their only typed vias name both outer layers or are tented.

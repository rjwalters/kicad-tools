- **Route-time spacing can newly fail on an existing range map** (Issue #9602).
  `--voltage-map` ranges used to collapse each net to its dominant endpoint before
  differencing, which could score a sign-flipping pair at 0 V and route it at the fab
  floor; the interval-aware table now enforces the census' worst-case endpoint
  combination, so a previously "clean" board can exit 3 with e.g.
  `0.400mm (required 3.200mm)`. Widen the copper spacing to the standard's
  requirement, or -- when the pair's true stress is device-bounded (e.g. a MOSFET
  `V_DS` across a correlated pair) -- declare an explicit `_pair_bounds` cap in the
  sidecar (see `kct voltage-map-merge`); a bound only ever lowers the pair's ΔV.

- **`kct check --migrate-waivers` carries evidence-bound waivers across the `ev3` -> `ev4` bump** (Issue #9454). For each `ev3` waiver it recomputes the `ev3` digest on the current board; on a match the entry is re-bound to its `ev4` hash with reviewer, date, reason and issue unchanged (plus `rebound_at` / `rebound_from` / `rebound_by`). A mismatch stays stale and a key that names no finding is reported as an orphan. Previews by default; `--write` applies it; a normal check never migrates, and its stale advisory for an `ev3:` hash names the command.

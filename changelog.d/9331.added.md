- **`kct pcb prune` and `kct fix-drc` report waiver keys their edit invalidates**
  (Issue #9331). Both commands move copper that geometry-embedded waiver keys
  name, silently turning formerly waived findings back into errors. When a
  `.kct_waivers.json` sidecar is discoverable, the commands now diff which
  entries waive something before vs. after the edit (running `kct check`'s
  findings pipeline on both states) and print a report-only summary: N keys
  invalidated, each with its rule and — when exactly one surviving finding
  has the same rule, nets, layer and item kinds — the key to re-waive.
  Silent when nothing was invalidated or no sidecar exists; exit codes and
  board output are unchanged. Under `--dry-run` the preview shows what the
  edit *would* invalidate.

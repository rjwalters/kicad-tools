- **Acute fold-back repairs on different nets can no longer land inside each other's clearance** (Issue #8930). `Autorouter.cleanup_artifacts` Step 6 planned every repair against one pre-repair collision snapshot, so two same-layer, different-net chords could each clear the old copper yet end 0.17 mm apart on a 0.2 mm rule. The planner now also checks each candidate against chords accepted earlier in the same run (`clearance=` on `plan_foldback_repairs`). Separately, the `sharp_trace_corner` rule's open-wedge test no longer raises `ZeroDivisionError` on exactly collinear doubling-back legs, and a new parity test pins that rule and the router's detector agree.

- **`same_net_band_edges()` warns when a stackup disables the band** (Issue
  #9226). The shared same-net slit-band resolver in
  `kicad_tools.router.via_clearance` still returns `(0.0, 0.0)` for a
  stackup the fab profile has no entry for, but now logs a warning naming
  the unresolved `(profile, layers, outer_oz, inner_oz)` tuple instead of
  disabling the guard silently. Its third parameter was also renamed from
  `copper_oz` to `outer_oz` to match the `get_dfm_entry` vocabulary; all
  call sites are positional, so no caller changes.

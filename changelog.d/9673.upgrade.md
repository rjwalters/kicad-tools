- **A previously clean board carrying copper arcs can now fail `kct check`** (Issue #9673). Boards with imported KiCad arcs (or arcs written by `kct apply`) that short or under-clear foreign copper were reported as clean; the pairwise clearance rule now sees that copper, so such boards gain `clearance_arc_*` errors. Review and reroute (or waive) any new arc findings — they name real copper overlap that every straight-segment equivalent was already failing.

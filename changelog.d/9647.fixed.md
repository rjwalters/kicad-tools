- **`kct pcb current-paths-audit` / `kct check --current-paths` no longer judge a sense branch buried in an endpoint pad at the full declared current** (Issue #9647). A thin branch (Kelvin/sense tap) whose first segment lies wholly inside a large endpoint pad was added to the resolved path as trunk copper, so the audit reported the path's minimum width as the tap's neck and `path_ampacity` raised a false "too narrow / would fuse" error on exactly the nets that carry sense taps. Wholly pad-internal copper now counts as path evidence only where the route rides it beyond the pad centre; a branch hanging off the pad terminal is excluded at either endpoint, while pad-internal trunk pieces and stubs to vias dropped inside a pad stay in the result.

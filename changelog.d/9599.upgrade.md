- **`route-auto` can now refuse its save** (Issue #9599). When the output
  board file is modified by anything else between the run's load and its
  save, the stale-write guard refuses to overwrite it (exit non-zero, clear
  error) instead of silently reverting the edit. Re-run `route-auto` against
  the current file; don't edit a board while a route-auto run holds it.

- **`mask_to_copper` now completes under `KCT_KICAD_DOCKER=1`** (Issue #9009). The full-layer Gerber export ran the host `kicad-cli` while the per-object worker ran the pinned image, so a host with a different KiCad release always reported `Native object/export versions differ`; both passes now run the pinned image's KiCad. Fractured zone fills (holes joined to the outline by zero-width bridges) are repaired the same way the Gerber reader repairs fill regions instead of being reported as `invalid native object polygon`, which had left every board with a filled zone incomplete. The refusal for a KiCad build outside the qualified plot profile now says to set `KCT_KICAD_DOCKER=1` or install a qualified release, and a missing native object is reported once instead of twice. The qualified versions are unchanged.

- **`portable_native_command` no longer mistakes an unknown docker flag's value for the image** (Issue #9080). A recorded `docker run` argv is reduced to `["docker", "run", <image>, <entrypoint>]` only when its flags are all in the vocabulary `docker_kicad_cli_prefix()` emits; any other flag (e.g. `--volume`, `--env`, `--name`, `--network`, `--mount`) now reduces the record to `["docker"]` instead of leaking the flag's value — potentially a host path — into hash-bound evidence.

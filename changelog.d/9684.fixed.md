- **MCP `measure_clearance` no longer skips authored copper arcs** (Issue #9684). The per-layer collector now walks `(arc ...)` copper beside segments, pads and vias, adapting each arc through the same shared validator element `kct check` uses, so a net pair that shorts at an arc no longer reports a false positive gap (or `No copper elements found`) through MCP. Measurements name the arc (`Arc-<uuid>`, type `arc`) and its signed minimum agrees with the CLI `clearance_arc_*` finding on the same board.

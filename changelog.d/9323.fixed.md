- **`kct` JLCPCB BOM merges lines sharing one LCSC part** (Issue #9323). `JLCPCBBOMFormatter` now groups by (footprint, LCSC) when an LCSC number is present, so BOM groups that differ only in `Value` text export as one line with all designators joined and the distinct values listed in `Comment` — previously JLCPCB flagged every such line ("Multiple lines in the BOM have been matched to the same part") and left it unticked, silently not fitting the parts. Rows without an LCSC number still group by (value, footprint). `submit-jlcpcb`'s BOM/CPL agreement and the regeneration read-back merge (`--merge-lcsc-from` / default CSV merge) accept the merged row's constituent values, so a merged line neither blocks submission nor loses its LCSC numbers on the next export.

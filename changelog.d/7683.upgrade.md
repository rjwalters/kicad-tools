- **`model_coverage` is now part of the default `kct check` set** (Issue
  #7683). The opt-in deferral from #7682 is gone: a footprint with no
  resolvable 3D model is one advisory warning, so `kct check --strict` now
  fails on it. A host without a model library still gets a single `info`
  finding. `--3d-models` is kept as a no-op.

- **A declined lattice diff-pair hybrid now names the stage that actually
  blocked it** (Issue #7931). The `Diff-pair hybrid (lattice) ... hybrid
  declined (...)` line printed by `kct route` reported the *first* trunk start's
  failure, so board 03's USB_D J1.A6->U2.3 read `trunk-offset-degenerate` even
  though later starts routed a trunk and failed at the leg. It now reports the
  furthest-progress decline (an over-budget leg, then any leg-stage failure,
  then trunk-stage ones) and names the trunk start and layer that reached it.
  Routed copper is unchanged.

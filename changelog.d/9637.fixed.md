- **`kct check` no longer compares a sibling revision against the wrong schematic** (Issue #9637).
  `project.kct`'s `artifacts.schematic` is now used for LVS / ERC / netlist-sync discovery only
  when the board being checked is the board the spec names (`artifacts.pcb` / `pcb_routed`,
  stage suffixes ignored); otherwise discovery falls through to the sibling schematic. The
  `spec_conformance` category is skipped with `board_not_spec_artifact` for such a board. The
  human output gains a `Schematic:` line and `meta_checks.schematic` (`path`, `source`) names the
  schematic used and how it was found.

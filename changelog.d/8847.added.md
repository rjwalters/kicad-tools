- **`kct check` flags negative mask expansion and multi-piece mask openings** (Issue #8847). New default-on `mask_negative_expansion` and `mask_multi_segment` categories (warnings, advisory) built on `inspect_mask_geometry`; coverage is reported `unknown` when the mask snapshot is incomplete, but these advisory categories are non-blocking, so an `unknown` never fails `kct check` on an otherwise clean board.

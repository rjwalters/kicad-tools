- **`kct check --migrate-waivers` keeps a symlinked waivers file a symlink** (Issue #9504). The atomic write resolves the path before replacing, so the update lands in the link's target instead of silently turning the path into a regular file and leaving the old entries there; a failed replace leaves the original bytes and no temp file behind. Orphan lines now say `[rule not evaluated in this run]` when the entry's rule could not run for lack of input (`ampacity` without a net-class-map, `path_ampacity` without `--current-paths`), and untouched `ev2:`/`ev4:`/`ev5:` and legacy entries are listed by key instead of only counted.

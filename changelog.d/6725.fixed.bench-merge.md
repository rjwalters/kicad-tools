- **Net length now matches kicad-cli on track junctions, pass-through pads and off-centre via ends** (Issue #6725). A bench comparison against kicad-cli 10.0.6 on boards 03, 06b, 06rf and 07rf found up to 0.57 mm per net of disagreement that the first kicad-length model missed. kct now joins track segments into lines the way kicad-cli does, so a track that passes through a pad centre is no longer clipped at that pad. A line that ends anywhere inside a via's copper is now clipped at the via and run straight to its centre. A via whose tracks use only one layer now gets zero height on the written board, as in kicad-cli. Every diff-pair net on the four bench boards now agrees with kicad-cli to within 0.1 µm.

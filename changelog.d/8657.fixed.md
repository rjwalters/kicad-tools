- **Routing no longer changes with scipy installed** (Issue #8657). The trace-width
  dilation (`RoutingGrid._dilate_blocked`) used `scipy.ndimage.binary_dilation`
  whenever scipy was importable, which was 8-17x slower on a large grid and
  treated cells past the grid edge as free instead of blocked, so the same board
  could route differently with the `bayesian`, `research`, `models` or `all`
  extras. It now always uses the NumPy path that scipy-free installs already ran.

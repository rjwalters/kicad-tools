- **`kct pcb prune` and `kct optimize-traces` no longer undo shaped near-pad geometry into creepage failures** (Issue #9640). `pcb prune` takes `--voltage-map` (plus `--creepage-standard`, `--pollution-degree`, `--material-group`, `--hv-threshold`) and drops any net's plan that leaves a pair further under its creepage requirement, reporting `rejected_by_creepage`, `creepage_pairs_checked` and `creepage_pairs_unchecked`. `optimize-traces`' whole-board creepage audit now compares per-pair shortfall instead of only the set of failing pairs, so under a range/`_pair_bounds` map a rewrite can no longer deepen a pair that already failed; its JSON gains the same pair lists and before/after failure counts. `optimize-traces` also leaves nets that own a locked track untouched (`locked_nets_skipped`); both commands' `--help` say what locking protects.

- **`kct check` stops failing boards on `pcb reinforce`'s own mask openings**
  (Issue #9315). `mask_to_copper` now attributes a run's strip, end-hole and
  anchor openings to their `<board>.reinforcement.json` record: the run's own
  track, anchor vias and same-net pads on the run measure as
  `within_reinforce_run` (info) instead of errors, and those findings name the
  owning net and run where they previously read `owner_net: null`. Copper of a
  different net inside a strip's clearance band is still an error, and
  same-net copper off the run is still reported. Without a sidecar (or with no
  matching record) the assessment is unchanged.

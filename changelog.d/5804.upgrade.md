- **`kct mcp serve` now requires the `mcp` extra, including for the default
  `stdio` transport** (Issue #5804). `jsonschema` moved from the core
  dependencies to the `mcp` extra; because `kicad_tools/mcp/server.py` imports
  it at module scope, a core-only install can no longer start the MCP server at
  all. Previously only the `http` transport needed the extra (for `fastmcp`),
  while `stdio` happened to work on a bare `pip install kicad-tools`. Install
  `kicad-tools[mcp]` (or `kicad-tools[all]`) if you run the MCP server --
  which is what `kct mcp serve` already tells you to do for HTTP. On a
  core-only install the command now exits 1 with
  `Error: ModuleNotFoundError: No module named 'jsonschema'`. No other
  command is affected: the CLI never imports the MCP subsystem at load time.

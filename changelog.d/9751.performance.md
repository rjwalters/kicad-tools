- **`EdgeClearanceRule` prunes the outline scan instead of paying one kernel call per outline segment** (Issue #9751). Certified arc tessellation (#9689) makes an Edge.Cuts outline 100–400x denser, which turned `min_gap_to_outline`'s brute-force scan into seconds per rule on arc-outlined boards; it now skips outline edges via a conservative bounding-box lower bound (bit-identical results) with the per-edge boxes cached across the whole rule invocation. Measured on a 1004-segment rounded-corner outline: 1.2–1.8 ms per copper item down to 21–33 µs (~40–85x), with the straight 4-sided outline unchanged.

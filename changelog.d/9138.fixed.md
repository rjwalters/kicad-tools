- **Match-group skew derived from a PCB no longer counts off-path copper** (Issue #9138). `derive_group_skew_data` now measures each member net's pad-to-pad copper path (plus the height of vias on it) instead of summing every segment, so a same-net dead-end loop, overlapping duplicate or stub can no longer hide real skew; off-path copper above 2 mm is logged as a warning. Nets with no pad-to-pad path (open nets, no shapely) keep the summed kicad-cli length.

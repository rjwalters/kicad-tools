- **`physical_copper_gap` no longer reports pad mask bridges on inner layers**
  (Issue #8913). The 2 oz pad mask-bridge check inside `physical_copper_gap`
  iterated every copper layer carrying a pad, so a single through-hole pad pair
  on a 4-layer board produced one `error` per copper layer — including inner
  layers, which have no solder mask to bridge, and each message interpolated the
  *outer* copper weight. The check now runs on `F.Cu` / `B.Cu` only, so a THT pad
  pair yields at most one finding per outer side. Thresholds are unchanged.

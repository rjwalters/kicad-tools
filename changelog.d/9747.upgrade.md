- **Action needed if you run `kct pcb prune` without `--current-paths` on a board that has a `current_paths.json` sidecar** (Issue #9747). Prune now auto-discovers the sidecar exactly as `kct check` does (printing `[INFO] auto-loaded current-paths sidecar: <path>`), so declared nets get the declared-current width test and doubled parallel copper is kept. Pass `--no-current-paths` (same name and semantics as on `kct check`) to restore the old behaviour of ignoring a nearby sidecar; an explicit `--current-paths` still wins, and an auto-discovered malformed sidecar is warned about and skipped rather than fatal.

- **Lattice router escapes fine-pitch pads whose full-width stubs dead-end** (Issue #6381).
  On a 0.65 mm pitch QFN row, a 0.4 mm trace's legal centreline band can fall
  between lattice rows, so the full-width escape only reached nodes inside the
  pad's own copper with no legal way out. Those dead ends no longer suppress the
  narrower-neck fallback (#4293), so board 05 PHASE_B (U2.8 -> J2.2) routes. A
  search that fails because one end's escapes are dead ends now declines as
  `no-egress-start` / `no-egress-end` instead of `no-path-layer-constrained`.

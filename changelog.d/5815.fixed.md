- **Label LVS no longer reports false mismatches on sheet-local net names**
  (Issue #5815, also covering the root-sheet form in #5809). The schematic
  side now qualifies a *local* label with its KiCad sheet path — `SENSE` on
  the root sheet becomes `/SENSE`, `DBG_LED` inside a child sheet named `MCU`
  becomes `/MCU/DBG_LED` — matching what `kicad-cli sch export netlist` and
  the board itself carry. Global labels, power nets and hierarchical
  label/sheet-pin nets keep their shared, unqualified identity. Two sibling
  sheets reusing one label text are now two distinct nets instead of one, so
  the copper leg no longer sees them as shorted together. `compare_netlists`
  additionally tolerates a board that spells the same node with a shorter
  sheet path (`MCU/DBG_LED`, `DBG_LED`) — but only when both sides put the
  same pads on it, so a wrong pad binding, a swap between two sibling sheets'
  same-named nets, and a board that merges them all still fail.

- **Opt-in via-footprint charging for per-pad routing budgets** (Issue #6415).
  The grid router charges the #3143 channel budgets and #6382 pad lanes at a
  via's centre cell only, so a via whose copper seals a foreign pad's lane
  while its centre sits just past the lane end pays nothing. Setting
  `KCT_PAD_BUDGET_VIA_SCALE` above 0 makes each via pay once for every budget
  its disc (radius including clearance) touches. The charge scales with the
  covered cells, is capped at the budget's long side and applies on every
  layer a through via spans. The default (0) keeps the centre-cell charge,
  because on board 05 the footprint charge moves PHASE_C's via onto U2.10's
  tip, where the pad-access guard refuses it. The native build is now 53, so
  run `kct build-native` again.

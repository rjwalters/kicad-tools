- **Board 04's fragment-run merge no longer fails on a stray short segment elsewhere in the chain** (Issue #9133). `merge_fragment_runs` used to commit to the *first* sub-0.1 mm segment it found, so a lone stray ahead of the real flagged run left the run unexamined and failed the whole regeneration with a misleading "no neighbour on both sides" diagnostic. It now walks every maximal sub-threshold run in the chain, merges the first one that passes the guards, and each rejection names its own reason (run too short, chain start, chain end).

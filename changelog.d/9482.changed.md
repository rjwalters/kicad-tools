- **`kct check --migrate-waivers` lists legacy-version waiver entries by key** (Issue #9482). A keyed entry whose evidence-hash version predates `ev3` (e.g. `ev2:`) used to be folded into the `untouched` count with no key shown; the report now lists each such entry with its version and a re-waive/delete hint, and no longer counts it as `untouched`.

- **`kct route --order-method greedy|critical_first|congestion|hybrid` now exits 2 on escalation paths** (Issue #5908). Previously the flag was silently ignored there. If a script passes one of these methods together with the default `--auto-layers` (or `--adaptive-rules`, `--auto-pcb-size`, `--auto-mfr-tier`), either add `--no-auto-layers` (and drop the other escalation flags) to route a single attempt that honours the order, switch to `--order-method crossing`, or drop `--order-method` to keep the routing you were actually getting.

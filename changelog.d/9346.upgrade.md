- **`kct readiness --verify` can newly fail where it used to pass** (Issue #9346). A retained CPL/BOM that cannot be read or parsed, a board the parser rejects, or an unexpected CPL rotation re-derivation error is now reported as a verification problem instead of silently skipping the CPL-vs-sidecar comparison, so a gate that exited `0` on such a bundle can now exit non-zero. `readiness.json` can newly carry `cpl_rotations.rederivation_skipped`; report consumers must accept the new key.

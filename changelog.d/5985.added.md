- **Generated PCBs can carry schematic pin types (`pintype`)** (Issue #5985).
  New `kct pcb annotate-pintypes PCB --schematic SCH` copies each schematic
  pin's name and electrical type onto its pad, as `(pinfunction ...)` and
  `(pintype ...)`, matching KiCad's "Update PCB from Schematic". Unconnected
  pins get the `+no_connect` suffix. Only those pad children change; the rest
  of the file is kept byte-for-byte. `kct pcb sync-netlist` now writes the same
  data, and board 04's generator annotates its PCB. As a result,
  `kct detect-mistakes` pin-type rail evidence (#5939) finds `+3.3V` and `+5V`
  on board 04 from pin types instead of names.

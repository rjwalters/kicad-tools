- **`kct check` no longer records absolute host paths when `mask_to_copper` runs** (Issue #9055). The native worker's docker prefix (per-run stage mounts, `HOME`/`KICAD_CONFIG_HOME` forwarding, `--user`) and the kicad-cli command (including the per-run docker shim path) were recorded verbatim into `kct-check.json`'s `geometry_provenance`, so the evidence failed the portable-paths scan (#6532) and no two runs reproduced the same bytes. Recorded commands now keep only the tool identity — docker argvs reduce to `["docker", "run", "<pinned image>", "<entrypoint>"]`, other commands to the executable's basename — and the per-run docker shim no longer contributes a `command_file_sha256`. The executed commands are unchanged. This changes `MaskSourceBinding.export_profile_sha256` for every board (the recorded command feeds the binding hash); committed mask-copper intents bound to an old hash need re-pinning.

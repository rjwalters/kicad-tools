- **`(severity ignore)` DRU rules no longer floor routing clearance** (Issue #9670). `kct route`'s `.kicad_dru` reader honoured `(severity ignore)` for conditional rules only: an ignored unconditional or via-scoped clearance rule still floored the run, so a board whose sidecar carried `(rule ... (severity ignore) (constraint clearance (min 0.9mm)))` was routed at 0.9 mm by a rule that enforces nothing. An ignored rule is now skipped in all three layers (unconditional, via-scoped, conditional), and the `board_clearance_rules` docstring no longer claims `memberOfFootprint` matches case-insensitively -- it is case-sensitive with `*` / `?` wildcards, as probed on `kicad-cli` 10.0.6. This can lower a resolved clearance on a board that carries such a rule; none of this repo's `boards/*/output/*.kicad_dru` does.

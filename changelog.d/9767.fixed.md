- **`kct check` diff-pair skew no longer counts defect copper** (Issue #9767). The
  same #9304 classifier the match-group producer uses now corrects each leg of a
  differential pair before the difference is taken — in `derive_pair_skews`
  (mm and ps, with the correction charged at the defect copper's own layer
  delay and the reported per-layer lengths kept consistent), the scalar mm API
  (`derive_skew_data` / `derive_skew_limits`, also the PCB retuning reader) and
  the series-chain sums of `derive_chain_skew`. A dead-end branch or
  terminal-rooted loop on one leg no longer inflates that leg's skew figure;
  rejoined length-matching copper, sub-epsilon structures and unavailable
  classifications keep the raw measurement, and `measure_pcb_net` retains its
  KiCad length contract. Measured on the committed board artifacts, every
  diff-pair leg classifies defect = 0.000 mm, so no committed figure moves.

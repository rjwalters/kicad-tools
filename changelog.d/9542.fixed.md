- **`kct check` resolves overlapping same-layer tracks as one wide conductor instead of reporting an ambiguous loop** (Issue #9542). Widening a power stretch with a second same-layer track that overlaps it along the run -- the ordinary way to get width where a single centred track would clip an obstacle -- was treated as a loop/parallel return path, so `path_ampacity` failed the declared path as `ambiguous`. Same-layer branches of a parallel group now qualify when their copper overlaps into one contiguous bar (centreline offset under half the summed widths), and the group is judged and reported at the merged copper's width -- two 1.0 mm F.Cu tracks offset 0.6 mm count as 1.6 mm, not the 2.0 mm a summed reading would claim. Same-layer tracks with a real gap (or a bare tangency) stay unsupported: the path remains `ambiguous`, with a message naming "parallel same-layer copper" and the supported alternatives (overlapping tracks, a zone, or a two-layer parallel group).

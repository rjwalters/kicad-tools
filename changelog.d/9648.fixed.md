- **`path_ampacity` credits a fully wired buttress wire** (Issue #9648). A
  leg `reinforcement_incomplete` accepts as fully wired (two end anchors, continuous
  mask opening, open rings) now has its wire's copper cross-section added to the
  trace's in both the IPC-2221 width check and the Onderdonk fusing check, so the
  documented `kct pcb reinforce` build no longer leaves dozens of "too narrow"
  errors on legs it wired completely. Messages say when a wire was counted
  ("width 2.400mm + 16 AWG wire = 21.100mm effective") and, on a wired net, name
  the stretch an error does belong to ("this stretch is not covered by a wire leg").
  A leg with any `reinforcement_incomplete` finding gets no credit, and boards with
  no wired legs check exactly as before.

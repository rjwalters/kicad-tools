- **`route-auto` refuses to save when the board changed under it** (Issue
  #9599). `route_net_auto` rewrites the output board wholesale from its
  in-memory copy; a file edited between the command's load and its save was
  silently clobbered. The save is now refused with a clear error (stale-write
  guard) when the output file's identity changed since the load. Scripts that
  edited a board while a `route-auto` run was in flight must re-run the
  command against the current file.

- **`kct route --report-detour-ratio`** (Issue #9003). Advisory per-connection
  detour report: drawn copper vs what the same search achieves alone on an
  empty board, with a distribution summary (median/p90/p99/max), the worst
  offenders above the ~1.25x threshold, and a stem-keyed
  `<output>.detour_ratio.json` sidecar. Connections the probe cannot route
  on the empty board are listed as probe-no-path, one row per failed edge.
  Opt-in diagnostic; the probe restores the router state it
  touches, so routed output is byte-identical with and without the flag
  (its wall-clock cost is excluded from the routing budgets, #9244). It
  never changes the exit code. Grid engine only.

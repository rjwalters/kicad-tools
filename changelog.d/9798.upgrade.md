- **Silk errors grade as errors under the jlcpcb profiles** (Issue #9798, operator ruling on #9795). `silk_over_copper` and `silkscreen_over_pad` (silk on exposed copper), `silkscreen_line_width` / `silkscreen_text_height` / `silkscreen_text_thickness` (below-minimum silk), and `silk_ref_obscured` / `silk_under_body` (silk hidden under a component body) now fail `kct check --mfr jlcpcb` / `jlcpcb-tier1` instead of warning. Every other profile keeps the legacy warning grading. Silk over a *via* is never an error: under these profiles an untented-via aperture hit grades as `info`, so a via-only board cannot fail through `silk_over_copper` either. The `silk_hole_overlap` severity split (PTH/NPTH error, via waived) is issue #9033 / PR #9112's change and lands separately. The committed `boards/*/output` artifacts report zero findings from the regraded rules; historical fixtures with deliberately buried designators (the pre-#6394 board-03 witness) now show their `silk_ref_obscured` findings as errors.

- **`path_ampacity` no longer silently passes a width-swap via between
  doubled stretches** (Issue #8950). A via where the parallel branches' width
  split flips (wide F.Cu / narrow B.Cu, then narrow F.Cu / wide B.Cu) carries
  real redistribution current, but the #8916 stitching scoping left it
  unjudged. `stitching` now also requires the copper's width to be the same
  on both sides of the via on every joined layer, so such a via stays a
  series layer change and is judged on the path's current (conservatively,
  the full path current). A mid-run stitching via inside one coincident
  doubled run, and a via whose split continues unchanged, are still
  unreported.

- **`kct check --sch-field-threshold` prints the limit it enforces** (Issue #9447). The `sch_field_offset` message formatted the threshold to one decimal, so `--sch-field-threshold 12.75` rendered as `threshold 12.8mm` on a finding whose limit was really 12.75 mm. The message now shows the threshold at full precision (the default still reads `15.0mm`); `required_value`, waivers and machine-readable output are unchanged.

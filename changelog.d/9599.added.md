- **`kct route` names the existing copper a plain run will replace** (Issue
  #9599). Without `--preserve-existing`, a run on a partly routed board
  replaces all top-level routing copper with its own fresh paths; it now
  prints, before routing starts, every net carrying input copper and points
  at `--preserve-existing` (lock existing copper in place and route around
  it) instead of staying silent.

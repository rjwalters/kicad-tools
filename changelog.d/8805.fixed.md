- **`kct check` no longer reports a false `fiducials_missing` for project-library fiducials** (Issue #8805). A footprint now counts as a fiducial when its library item name starts with `Fiducial` (any library nickname), its reference matches `FID<n>`, or its tags contain `fiducial`; `kct pcb add-fiducials` shares the predicate, so it no longer duplicates them.

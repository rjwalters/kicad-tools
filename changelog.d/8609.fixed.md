- **Pure-Python router no longer runs on MLX/CuPy grid arrays** (Issue #8609). `Router` now moves a GPU-backed grid to NumPy up front (~30x faster on such a grid), and `RoutingGrid._select_backend` reports the real backend type for `ArrayBackend` (it previously logged `cpu` for an MLX grid). The default `kct route` path builds grids without a `PerformanceConfig`, so this is a defensive guard there; the cause of the reported slowdown is not established by this change. `cupy-cuda12x` carries a `sys_platform != 'darwin'` marker so `uv sync --all-extras` resolves on macOS.

- **`kct check` no longer runs the native mask worker under a blind `/usr/bin/python3`** (Issue #8946). The per-object geometry helper now discovers an interpreter that actually imports `pcbnew` (KiCad.app's Python.framework on macOS, `PROGRAMFILES` installs on Windows), runs inside the pinned `kicad/kicad` image when `KCT_KICAD_DOCKER=1`, and records the command it used in the report provenance. An explicit `native_python_command` still wins; when nothing with `pcbnew` can be found, the recorded reason says what to install or configure instead of surfacing `ModuleNotFoundError`.

- **`kct route-auto` emits copper at the net's class width** (Issue #9716). The
  global corridor materialised every net at the board-default
  `DesignRules.trace_width`, so a `BUS` net authored into a 0.6 mm `Wide`
  netclass or a `PHASE_A` net name-classified `HIGH_CURRENT_SIGNAL` (0.4 mm)
  came back at 0.2 mm — a current-capacity defect. The corridor now resolves
  the width with the census's priority (authored `.kicad_pro` netclass first,
  then the classification map, then the rule default); nets with no class
  override keep the default width, and sub-class copper the hierarchical
  strategy still produces stays reported via `necked_copper`.

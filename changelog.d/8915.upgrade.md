- **Re-running `kct pcb reinforce` places fewer anchors on legs under 15 mm**
  (Issue #8915). `ends` mode now applies a default 15 mm minimum
  buttress-wire length, so a board whose legs are shorter than that gets
  *fewer* anchors than before — and no solder-mask openings and no
  `<board>.reinforcement.json` entries for those legs. Pass
  `--min-wire-length 0` to keep the previous output. Anchors already on a
  board are not removed by this change; use `--clear` / `--replace` for that.
- **A short declared current path can newly warn in `kct check`** (Issue
  #8915). Where a path declared `reinforcement_eligible` has only a leg below
  the minimum, that leg now carries no wire, so `reinforcement_incomplete`
  reports its `a` (no anchor holes) and `b` (no continuous solder-mask
  opening) sub-checks for the net. Both are **warnings**, not errors. Either
  drop the `reinforcement_eligible` declaration for a link too short to carry
  a wire, or pass `--min-wire-length 0` to anchor it as before. The
  `reinforcement_incomplete` rule itself is unchanged by this release.

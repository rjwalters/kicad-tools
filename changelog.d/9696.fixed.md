- **Grid router: the C++ backend no longer fires the own-net slit-band gate-off retry on a wall-clock-timed-out search** (Issue #9696). The wrapper's retry predicate now mirrors the pure-Python pathfinder's deadline guard: a first search that ended on its per-net wall-clock deadline (`FAILURE_TIMEOUT`) is a drained budget, not a gate-caused failure, so it is returned as-is instead of paying a second full search that would fail the same way. Both backends now make the same gate-off retry decision, so a net can no longer come back routed from the C++ engine and unrouted from Python on this path; ordinary no-path exhaustion and gate-caused failures still get their one counted, logged retry.

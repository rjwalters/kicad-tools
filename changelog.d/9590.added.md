- **`kct probe` and `kct apply --checked`: batch check-then-write for hand-scripted copper** (Issue #9590). `kct probe <pcb> <items.json>` checks a whole batch of proposed segments, arcs and vias (a JSON items file, absolute board mm) against the board and against each other, using the same rule set `kct check` runs; only findings the batch adds are reported, so pre-existing board problems never fail a probe. Exit 1 on any problem, naming the clashing item. `kct apply <pcb> <items.json> --checked` probes first and writes only when every item passes: atomic write (temp file + rename), backup at `<pcb>.kicad_pcb.bak` (`--backup` to move it), and refusal (exit 2, nothing written) when the board changed on disk between read and write. Both are `--format json`-capable and exposed over MCP as `probe_items` / `apply_items_checked`.

- **`kct check` / `kct pcb current-paths-audit` label a parallel group that is both merged and summed as "merged+summed", not plain "merged"** (Issue #9560). Since #9542 a group can carry an overlapping same-layer pair *and* a branch on another layer; both surfaces picked their noun from a single `same_layer` boolean, so 1.4 mm of merged F.Cu copper plus 1.0 mm on B.Cu printed as `(merged parallel group)` / `merged width 2.400mm` -- inviting the misreading that 2.4 mm is one contiguous bar. `ParallelGroup` now derives a three-way `shape` (`merged` / `summed` / `merged+summed`) from the same per-layer grouping that computes `width_mm`, and both surfaces word it from that: `(merged+summed parallel group)` and `merged+summed width`, i.e. merged within a layer, summed across layers. The single-layer-merged and all-distinct wordings are unchanged, and no width number, grouping rule or JSON key changes (`MinimumWidth.merged` is replaced by `MinimumWidth.shape`).

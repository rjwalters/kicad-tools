- **`kct check` match-group skew no longer counts defect copper** (Issue #9304).
  Each member's figure is its summed kicad-cli length minus the track copper one
  uniform topological classifier isolates as defect -- dead-end branches and
  same-net loops rooted at one pad/via terminal, counted per connected structure
  against `OFF_PATH_REPORT_EPSILON_MM` (4.0 mm). The same rule measures every
  member of every group; there is no per-member cutoff. The router tuner's
  rejoined cycle copper (length-matching bumps, parallel detours) and the benign
  pad/via escape residual stay counted, so on defect-free copper the figure is
  the summed length byte-for-byte. `measure_pcb_net` is unchanged.

- **`kct check --migrate-waivers` names every never-run rule on an orphan waiver** (Issue #9529). The inactive-rule set now derives from the recorded `skipped` coverage states instead of hand-mirroring two `coverage.precheck` conditions, so orphans naming any input-driven rule (reinforcement, physical copper gap, THT/SMD spacing, routing policy, match-group skew, diffpair skew/continuity/uncoupled length, opt-in width consistency and mask-to-copper) get the accurate "[rule not evaluated in this run]" wording, not the generic "the key changed or the defect is gone".

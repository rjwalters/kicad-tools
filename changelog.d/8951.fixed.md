- **`kct pcb reinforce --strategy parallel` re-runs no longer accrete
  stitching vias when the sidecar record is missing** (Issue #8951). A
  record-less re-run now adopts an unowned, size-matched, same-net through
  via lying on the leg inside the copy span instead of nudging a fresh set
  in beside it; adopted vias are credited to `existing_vias` (and the text
  report now shows `[N via(s) already present]`) but stay out of the record,
  so `--clear` still cannot remove copper the tool did not place. `kct
  check` also credits a fully pre-existing copy: a `copy_status: placed`
  record with empty `copy_segments` (a leg doubled by hand) no longer raises
  `reinforcement_incomplete` subchecks a/b, while coverage is now checked
  along the whole recorded copy extent, so deleting an unrecorded piece of a
  placed copy is caught.

- **`kct check` can newly fail a board whose outline lives in a footprint**
  (Issue #9593). Footprint-local `Edge.Cuts` graphics now count as board
  outline, so `copper_edge_clearance` (edge clearance) fires for copper near
  a footprint-drawn outline where `kct check` never reported it before --
  the new findings are the same ones `kicad-cli pcb drc` reports on such
  boards (e.g. SparkFun's IoT RedBoard ESP32-P4). Boards whose outline is
  drawn with board-level `gr_*` graphics on `Edge.Cuts` are unaffected.

- **`kct route --voltage-map` can newly fail boards with copper near the board edge** (Issue #9685). The new copper-vs-board-edge audit column means a run that previously exited 0 can now roll back `--complete` links (reported as `creepage-rolled-back` with blocking net `<board edge>`) or exit 3/4 listing `/NET vs <board edge>: X.XXXmm (required Y.YYYmm)` rows. Boards whose HV copper genuinely owes edge creepage must move it inward (or add an `_edge_voltage` reference to the map when earth is not 0 V); a board that fails `kct creepage` on its `net vs <board edge>` rows was never safe to ship. The measurement is straight-line distance, slightly stricter than the census's bridged surface path: a slot between the copper and the outer edge can make the census pass a pair this gate flags.

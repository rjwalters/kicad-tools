- **`kct fix-drc` repairs same-net `physical_copper_gap` slits** (Issue #9332,
  split from #9326). New `--only copper-gap` pass (also part of the default set
  when the report carries such findings): a via beside its own pad is moved
  along the pad-centre ray until the gap clears the finding's required value —
  or snapped to the pad centre when the profile declares a via-in-pad process —
  and a track tangent to its own via has the via snapped onto the track's
  centreline so the copper fully merges. Detection and the post-repair
  re-check run `kct check`'s rule set with the stackup's fab-view gap bands
  resolved. Different-net gaps are never touched; a move that would crowd
  foreign copper or drill too close to another hole is declined and listed as
  unrepaired with a reason.

- **`mask_to_copper` findings are now triageable, and an incomplete run no
  longer reports errors** (Issue #9038). Each finding names the mask opening's
  owner (`pad:<ref>/<num>` when the source footprint identifies it, otherwise
  kind + UUID prefix), the exposed copper's kind and net, and classifies the
  exposure as `same-net own-pad entry`, `same-net pass-through` or
  `different-net`. While the assessment's coverage is incomplete, findings are
  provisional: capped at warning severity and marked `provisional: coverage
  incomplete`, so an unfinished run never inflates the error count. A closing
  `mask_to_copper_openings` info finding counts the findings per opening, so
  one pad with many findings reads as one opening.

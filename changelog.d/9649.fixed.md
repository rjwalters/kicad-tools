- **`kct pcb reinforce` mask openings are no longer refused for far-side crossings** (Issue #9649). The opening's creepage test now sees copper, pads and zone fills on the opening's own face plus through-plated features (vias, PTH pads) on any layer, instead of treating every layer's copper as an obstacle; a bottom-layer trunk crossed on the top layer gets its opening. Far-face copper still blocks where a non-plated opening shortens the surface creepage path -- an NPTH bore, an `Edge.Cuts` slot/cutout or the board outline -- with the far face tested only for samples within the requirement of such an opening. The anchor-hole test stays layer-agnostic. A refusal now also names the obstacle's layer (or `through`), kind (`track`/`via`/`pad`/`zone`) and coordinates -- in the CLI line, the JSON `refused_openings` entries (`obstacle_layer`, `obstacle_kind`, `obstacle_at`, additive) and the leg's `mask_reason` -- which is also where the leg would have to be split to open around a same-face blocker.

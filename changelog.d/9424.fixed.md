- **Router stops seating vias in a slit beside their own SMD pad** (Issue #9424).
  The same-net pad slit band treated any overlap of a pad's bounding box as a
  copper union, so the C++ A* (and the stitcher, escape, link and lattice
  producers that share the predicate) could place a via in a `roundrect` pad's
  corner air or 5 um onto a flat face. Both leave a slit that
  `physical_copper_gap` grades as an error. A via now counts as joined to its
  pad only when it overlaps the pad's inscribed stadium by the depth the
  checker needs (0.0218 mm for a 0.6 mm via at a 0.15 mm edge). On board 05's
  unattended route this drops `kct check` errors from 8 to 1 on seeds 42, 7 and
  1337. Native router build version 76: run `uv run kct build-native`.

- **`kct pcb reinforce --strategy parallel` ties a high-current SMD end with a
  via row, not one via** (Issue #8950). With `--current-paths` declared, the
  tie at an SMD-pad end is now a packed row of stitching vias whose summed
  barrel capacity meets the path's declared design current (one via per
  `ceil(I / via_barrel_current_capacity)`, stepping inward at `kct stitch`'s
  same-net minimum centre spacing), so `path_ampacity` no longer reports that
  end as an under-capacity layer change. Every row via is recorded in the
  sidecar, so `--clear` / `--replace` remove them all; a row that does not
  fit whole (blocked by an obstacle, or the leg is too short) refuses the
  copy whole, naming the shortfall and the governing rule. Without
  `--current-paths` there is nothing to size a row from, so an SMD end keeps
  its single tie via exactly as before. This retires the known limit recorded
  with #8916.

- **Trace optimizer can shorten long "tent" detours** (Issue #8217). New
  `shorten_detour_pass` replaces a whole chain of 3+ segments with a straight or
  single-bend 45° path between its endpoints when it is shorter and clear.
  Controlled by `OptimizationConfig.shorten_detours` (default on). The pass
  only runs when `TraceOptimizer` is given both a collision checker and
  `net_anchors` (same-net pad/via positions, so mid-chain pads stay connected);
  otherwise it is a no-op, so `kct optimize-traces` is unchanged until it
  supplies a board model.

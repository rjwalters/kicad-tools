- **`kct pcb current-paths-audit` names a merged same-layer group's width "merged", not "summed"** (Issue #9557). Since #9542 a parallel group can be overlapping same-layer copper whose reported width is the merged union extent, but the audit's text line still annotated every group figure as `(summed parallel group)` -- inviting the misreading that a 1.6 mm merged bar is two summed tracks. The annotation now picks the noun from the group's shape, exactly as `path_ampacity`'s message already does: `(merged parallel group)` for same-layer merged copper, `(summed parallel group)` for a true sum across layers. No width number, grouping rule or JSON key changes.

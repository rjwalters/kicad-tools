- **`kct check` Gerber reader rejects aperture macros named `C`/`R`/`O`/`P`** (Issue
  #8997). A `%AM` macro shadowing a standard aperture template resolved before the
  standard `C`/`R`/`O`/`P` templates, so a malformed file silently flashed the macro's
  geometry instead of the standard aperture's. Reserved names now reject the layer at
  macro definition; conforming KiCad output (only `%AMRoundRect`) is unaffected.

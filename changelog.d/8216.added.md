- **`kct pcb prune` removes redundant copper** (Issue #8216). Builds per-net connectivity the way KiCad does (endpoint-anchored track joins, track ends inside the full pad/via/zone shape — never capsule overlap), removes redundant branches and same-layer loops only when every pad/zone terminal stays connected and no joint becomes overlap-only, snaps off-centre ends onto via/pad centres, and (with `kicad-cli`) drops any edits that add violations under `pcb drc --refill-zones` using the board's own `.kicad_pro`. Without a DRC check (`--no-drc` or no `kicad-cli`) the file is not written unless `--unverified` is passed.

- **`kct check` no longer aborts on the stock SOT-89-3 footprint** (Issue #9468).
  The pad-grid check measures a `custom` pad by its placement instead of
  refusing it as unroutable, so the whole run completes with a report. Strict
  connectivity and `track_dangling` now use the custom pad's real copper (anchor
  plus filled polygons), so a track ending on the tab counts as connected and
  one ending clear of it is still reported. Routing keeps refusing custom pads
  it cannot represent.

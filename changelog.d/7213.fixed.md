- **`PCB.add_footprint` keeps the `Library:Footprint` lib ID** (Issue #7213). Footprints added via add_footprint / kct sync / pcb sync-netlist no longer drop the library nickname, clearing kicad-cli `footprint_symbol_mismatch` parity warnings. `add_footprint_from_file` gains an optional `library_id`, and the sync reconciler now treats a nickname drift (`Capacitor_SMD:X` vs `Resistor_SMD:X`) as a real footprint mismatch.

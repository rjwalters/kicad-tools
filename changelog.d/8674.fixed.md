- **`kct route`'s chained completion pass now runs under the recipe's layer, HV,
  edge and current-path constraints** (Issue #8674). The `--complete` pass that
  `kct route` chains after a grid route was started without the outer run's
  `--layers`, `--voltage-map` (and `--creepage-standard`, `--pollution-degree`,
  `--material-group`, `--hv-threshold`), `--edge-clearance`, `--current-paths` and
  `--no-current-paths`. It re-detected a layer stack from the routed board, which
  on a KiCad 10 board with inner pours makes `In1.Cu` a signal layer, dropped the
  HV pairwise table, and used the manufacturer's edge clearance. All of these are
  now forwarded. Declared current paths are audited by the post-route DRC rather
  than planned by a search, so a pass whose copper adds a `path_ampacity` error is
  refused with a message and the negotiated board is kept. A new guard test reads
  the option list from the real parser and fails when a `kct route` option is
  neither forwarded to the pass nor listed as excluded with a reason.

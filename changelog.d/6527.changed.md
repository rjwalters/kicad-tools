- **Removed the unused bidirectional Python A*** (Issue #6527). Board 05
  measured flag off vs `--fallback-bidirectional` (2 runs each): the flag never
  engaged (0 bidirectional searches; the longest fallback request is 470 cells,
  under the 1000-cell threshold) and the routed copper was byte-identical.
  Forcing it on every fallback made the fallback 14-28x slower with the same
  7/17 searches succeeding. `Router.route_bidirectional`, `Router.route_auto`
  and their helpers (~1,080 lines) are gone; the Python fallback always runs
  the one-way `Router.route`.

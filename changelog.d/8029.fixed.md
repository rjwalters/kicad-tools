- **`kct route`'s post-route clearance backstop no longer deletes whole nets
  over attach-zone gaps** (Issue #8029). A router net-class clearance shortfall
  inside a #4506 attach zone that lists both nets (layer-scoped as in #4699) is
  now waived, using the same rule as the search and as
  `kct creepage --waive-attach-zone`. Designer `.kicad_pro`/DRU minimums stay
  strict. A real violation now removes only the offending connection's copper
  (the violating segment or via and the copper left dangling from it). The net
  reports partial instead of unrouted, and the log names the connection, for
  example `demoted connection U11.4 -> R3.2`.

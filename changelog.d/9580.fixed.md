- **`kct route` keeps the input uuid of every preserved track and via** (Issue #9580). Copper carried through a pass unchanged used to be re-emitted with a freshly minted uuid each time, so after `--complete` there was no way to tell router-added copper from pre-existing copper other than a geometric diff against the pre-route file. The parser now captures each item's `(uuid ...)` and `to_sexp` re-writes it, matching KiCad's own stable-across-saves behaviour; router-created items still get fresh uuids, and deterministic-uuid mode (#3272) is unchanged.

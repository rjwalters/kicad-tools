- **`kct fix-drc --only mask-copper` no longer keeps a re-centre that creates a new clearance error** (Issue #9365). The repairer's gate uses the manufacturer floor, which is below a net class's clearance, so the post-save re-check now reverts a move when a non-mask error absent from the pre-move board appears next to it (`new_drc_error`). If reverting a move fails, the board is restored from a snapshot instead of keeping a move the run reports as not made.

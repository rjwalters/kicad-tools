- **`scripts/ci/check_pr_checks_present.py` distinguishes "no checks ran" from "checks passed"** (Issue #5701). Stacked PRs (base is a feature branch) never trigger `ci.yml`, so `mergeStateStatus: CLEAN` there means "never ran". The script exits 3 on an absent rollup (2 failing/pending, 0 passing); documented in `docs/contributing/stacked-prs.md`. `.loom/scripts/merge-pr.sh` is Loom-managed, so the gate is repo-owned.

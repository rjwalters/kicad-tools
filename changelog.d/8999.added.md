- **`kct route --airwire-separation-weight` prices unrouted desire lines**
  (Issue #8999). New opt-in negotiated-driver cost term: each cell is
  priced by how many still-unrouted nets' straight-line desire lines cover
  it, so paths that keep other nets' pending connections open are preferred.
  Default `0.0` (off) is byte-identical to the previous cost model.
  Measured A/B on boards 02/03 and the synthetic mains fixture: no
  completion gain, via/wirelength regressions on two of three boards, so
  the flag stays opt-in — see
  `docs/research/kct-route-airwire-separation-experiment.md`. Native build
  version bump 66 → 67 (`kct build-native` required after pulling).

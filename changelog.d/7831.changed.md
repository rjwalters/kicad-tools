- **`kct route` chains a `--complete` pass when the grid route leaves signal nets open** (Issue #7831, Part of #4410). After a grid-engine route, if signal nets are still unconnected, one in-process lattice completion pass (existing copper fixed, #4413 guard active) runs on a staging copy of the output before the exit code is decided and is promoted only when it exits cleanly and closes a net (it works under `--timeout`, and is skipped when under 90 s of that budget remain). It uses the board's own rules; recipe flags such as via size, `--grid` and `--layers` are not forwarded. Fully routed boards skip it entirely. Opt out with `--no-chain-complete`.

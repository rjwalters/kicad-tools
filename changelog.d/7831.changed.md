- **`kct route` chains a `--complete` pass when the grid route leaves signal nets open** (Issue #7831, Part of #4410). After a grid-engine route, if signal nets are still unconnected, one in-process lattice completion pass (existing copper fixed, #4413 guard active) runs on the output before the exit code is decided; on board 05 this closes VCP (37/37). Fully routed boards skip it entirely. Opt out with `--no-chain-complete`.

- **`kct check` / `kct readiness` warn when DRC would run on KiCad's default rules** (Issue #8643). New `project_missing` / `project_default` findings (a missing or pcbnew-stock `.kicad_pro` with no `.kicad_dru`) print to stderr and appear in a new always-present `project_rules` list in `kct check --format json`; `kct readiness` records `project_default` under `warnings`. Findings are warnings and do not change the exit code.

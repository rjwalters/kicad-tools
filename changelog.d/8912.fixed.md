- **`reinforcement_incomplete` `[no_wire]` / `[skipped]` findings no longer land one board origin off** (Issue #8912). On a board whose `board_origin` is not `(0, 0)`, both kinds reported a location with the origin added twice — e.g. a path at sheet `(205.58, 143.0)` on a board with origin `(68.5, 55.0)` was reported at `(274.08, 198.0)`, outside the board outline and unclickable in the KiCad GUI. The rule now emits these locations in the board-relative frame like every other rule, so `DRCChecker` adds the origin exactly once. Other sub-checks (`[a]`/`[b]`/`[c]`/`[d]`, end-window) and `wire_run_courtyard_overlap` were already correct and are unchanged.

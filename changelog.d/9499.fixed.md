- **`.kicad_dru` loosening gate catches an `In1.Cu`-scoped rule masking the other inner layers** (Issue #9499). The probe set adopted for #9422 (`F.Cu`, `B.Cu`, `In1.Cu`) used `In1.Cu` as the only inner representative, so a hand-written rule scoped to `In1.Cu` alone raised it while `In2.Cu` and beyond resolved lower and were no longer probed at all. The gate now also probes the smallest inner layer no rule names, so no `(layer "In<N>.Cu")` rule can stand in for the inner class.

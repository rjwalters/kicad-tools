- **`kct check` can newly exit non-zero (exit 2, `INCOMPLETE`) when the checked
  board has no discoverable schematic** (Issue #9637). A `project.kct` one
  level up that names a different board no longer supplies its
  `artifacts.schematic` to a board revision whose own directory holds no
  `.kicad_sch`: ERC and LVS report `NOT RUN`, and when the other checks pass
  the overall verdict is `INCOMPLETE`, which exits 2 by default. Revisions with
  a discoverable sibling schematic are unaffected. To restore schematic checks,
  pass `--schematic <path>` for the checked revision, or, when the spec
  describes this revision, set `artifacts.pcb` or `artifacts.pcb_routed` to its
  board and ensure `artifacts.schematic` points at its matching schematic. For
  an intentionally schematic-less check, `--allow-incomplete` permits exit 0
  when incompleteness is the only problem; the verdict remains `INCOMPLETE`
  and other failures still yield a non-zero exit.

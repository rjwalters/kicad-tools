- **Evidence-bound waivers no longer go stale when only the board outline moves** (Issue #9431). Widening or shifting the Edge.Cuts rectangle (e.g. `kct pcb edit-outline --set-outline rect`) moved the board origin, and the evidence hash covered each named footprint's board-relative position, so every footprint-bearing waiver (`netclass_clearance_copper` and the rest) turned STALE although no copper moved. Footprint positions are now hashed in sheet (file) coordinates.

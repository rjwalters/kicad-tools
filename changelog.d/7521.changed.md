- **Diff-pair skew bumps obey the Q16 geometry gates** (Issue #7521). The
  post-route skew tuner caps a bump's excursion at 2x the pair gap (it adds
  loops instead of going taller), spaces loops so every jog is at least 3x the
  trace width, and places a bump only within 15 mm of a mismatch source in
  the same via-delimited run (the run's pad or via ends, or a partner via on
  it). Gates are measured on the generated geometry, square or chamfered. A
  skew that needs more room than the gates allow is closed only partly, so the
  pair can keep a skew error where it was tuned before. A tuner pass that
  runs out of host segments after a committed insert now keeps that insert
  instead of dropping it.

- **`kct export` no longer refuses a 2 oz board that has a hand-written unscoped clearance rule** (Issue #9422). The `.kicad_dru` loosening gate probed an abstract "no layer" view when a split-floor profile (`outer`/`inner`-scoped rules) was written, so that view saw only the hand-written rule (e.g. 0.127 mm) and reported `dru.resolved.track_track: lowered 0.15 -> 0.127`. It now probes concrete copper layers (`F.Cu`, `B.Cu`, `In1.Cu`) whenever `outer`/`inner` rules are present. Real loosenings on a concrete layer are still refused.

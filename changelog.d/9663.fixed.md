- **`route-auto` stale-write guard closes its load-window race** (Issue
  #9663). The output file's identity snapshot was taken after the board was
  read and parsed, so an external edit landing inside that window was part of
  the signature yet missing from the run's in-memory copy, and the save
  silently clobbered it. The snapshot is now taken before the board file is
  read; a write between the snapshot and the read only false-rejects (the
  safe direction).

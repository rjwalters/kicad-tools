- **`kct optimize-traces` keeps a net's safe edits when one edit would disconnect a pad** (Issue #8298). The connectivity check (#8250) used to discard a net's whole rewrite. The rewrite is now split into independent regions, and each region that keeps connectivity on its own is kept; the summary reports the nets kept in part (`nets_connectivity_partial` in JSON).
- **Optimizer chains no longer split where a route on another layer shares a vertex** (Issue #8298). `sort_into_chains` keyed vertices by position only, so two routes on different layers through the same points (e.g. both sides of a THT pad) read as four-way junctions and every chain pass saw single segments. Branch anchors for the per-pass guard (#8269) are now same-layer only, and an end within half a trace width of a pad or via centre no longer counts as dangling.
- **`kct pcb prune` finds loops closed by KiCad's anchor-in-shape joins** (Issue #8298): a track end on another track's centre line, and a via or pad centre under a track. Such an end does not count as a clean joint, so prune never thins a run to overlap-only joints, and a removal may not leave a via joined on fewer layers than before.

- **Derived HV creepage and clearance now default to reinforced insulation**
  (Issue #7082). `kct creepage --standard`, `kct audit --hv-standard` and the
  `kct readiness` HV isolation gate assume a reinforced (mains-to-SELV)
  barrier unless told otherwise: clearance uses the next-higher rated impulse
  voltage (230 V at OVC II: 1.5 mm -> 3.0 mm) and required creepage doubles
  (230 V, group I, PD2: 1.25 mm -> 2.5 mm). Layouts that passed before can
  newly fail. Pass `--insulation basic` / `--hv-insulation basic` only for a
  gap that genuinely needs basic insulation (for example line-to-neutral);
  never for a mains-to-SELV boundary. At 1000 V and OVC IV the reinforced step
  is above the top of the table and the lookup now fails loud. Router and
  placement HV spacing (`kct route`, placement HV domains) are unchanged and
  still use basic creepage.

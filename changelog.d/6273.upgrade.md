- **`kct route --timeout N` routes for less than N seconds** (Issue #6273).
  `--timeout` is still the hard total, but the routing loops now stop at
  `N - max(60 s, 15% of N)` (at most 25% of N), so optimize / save / zone fill
  / DRC can finish inside N. The `--auto-fix` reserve is added on top, and the
  two together are capped at half of N. A run whose routing already finished
  early is unaffected. A recipe that relied on routing using all of N should
  raise `--timeout` by the reserve, or set `--search-timeout` for its routing
  stage. When the post-route DRC is skipped for time, the board is reported as
  unverified: run `kct check` on it.

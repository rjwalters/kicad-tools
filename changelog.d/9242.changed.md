- **Fab DFM parity `table_version` is now derived from the table contents** (Issue #9242).
  `TABLE_VERSION` in `validate/fab_dfm_parity.py` is a short SHA-256 of `PARITY_TABLE`
  instead of a hand-picked counter, so concurrent PRs editing different rows no longer
  collide on the next number; the `table v<id>` stanza header and the
  `fab_dfm_parity.table_version` JSON field carry the same identifier.

- **`silk_over_mask_opening` messages quote sheet-absolute coordinates** (Issue #8879). The `mask opening (fp_*/gr_* …) at (x, y)` text used board-relative coordinates, so on a board with a non-zero origin it disagreed with the PCB file's `(at ...)` values. Waiver matching keys on the normalized item refs, not the coordinates, so existing waivers are unaffected.

- **A `kct route` run that chains a completion pass may now close fewer nets**
  (Issue #8674). If the recipe passes `--layers`, `--voltage-map`,
  `--edge-clearance` or `--current-paths`, the chained pass used to ignore them
  and could close links on a plane layer, inside the edge clearance or inside an
  HV pair's creepage distance. It now honours them, so those links stay open and
  the run reports them as unrouted. Boards routed that way before should be
  re-routed and re-checked with `kct creepage` and `kct check`; a link that only
  closed by breaking a constraint needs a placement, stackup or recipe change.
  Recipes that pass none of these flags are unaffected.

- **`load_bom_csv` prefers the first non-empty LCSC column when headers collide** (Issue #9402). Two differently-spelled columns that normalise to the same key no longer let a blank later column discard a populated earlier one. The CSV loader's `_norm_csv_header` docstring no longer claims the two readers accept the same spellings — only the normaliser is shared; the accept-lists stay intentionally separate.

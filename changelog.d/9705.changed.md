- **Test cases that need the C++ router backend now fail instead of skipping** (Issue #9705). A missing `router_cpp` extension used to silently skip ~116 modules' worth of native parity tests (`skipif(not is_cpp_available())` / `importorskip("kicad_tools.router.router_cpp")`), so a worktree or CI leg whose `kct build-native` step broke reported a green run with every native case missing. Those cases now fail with `C++ router backend not built: run uv run kct build-native` via the new `requires_router_cpp` marker / `require_router_cpp()` helper, and a guard test (`tests/test_router_cpp_no_skip_guards.py`) rejects any newly introduced skip guard on this backend. Run `uv run kct build-native` before `pytest` in fresh worktrees; the DRC and placement extensions are unaffected.

- **`kct probe` / `kct apply` items files now validate fields per item type**
  (Issue #9618). A field meaningless for the item's `type` — a `segment`
  carrying `mid`, a `via` carrying `layer` or `width` — is rejected with an
  error naming the 1-based item index and the offending field(s), instead of
  being silently dropped; a segment with `mid` is told to use
  `"type": "arc"`. An arc missing `mid` now raises that indexed diagnostic
  instead of `KeyError`.

- **Diff-pair skew tuning no longer rejects a bump for a near-miss its host segment already had** (Issue #7612). The foreign-clearance gate behind `apply_diffpair_length_tuning(engage="checker_skew_limit")` and `kct retune-lengths --diffpair` judged every trombone segment, including the leg that joins the host line, so a lane routed 0.156 mm off its sibling (limit 0.2 mm) vetoed every placement. A bump is now rejected only when it sits nearer a foreign pad, via or track than the pair's own route already does. Board 07's recipe now length-tunes TMDS_D2, MIPI_DAT0, MIPI_DAT1 and MIPI_CLK (skew 0.730 / 4.060 / 1.021 / 4.854 mm down to 0.045-0.067 mm), and the gap-tightening pass now finishes MIPI_DAT1 (Zdiff 130.5 to 100.0 ohm); their six allowances are deleted.

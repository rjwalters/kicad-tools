- **`kct parts search` ranks exact resistance matches first** (Issue #9474). A
  query carrying a unit-bearing resistance (`8.2Ω`, `4k7`, `10k`, `2.2 ohm`) now
  re-ranks the returned page so parts of that nominal precede other decades
  when both appear; parts with unparseable values are kept after exact matches.
  The table and text output now show the part description so the decade is
  visible: keyword search itself cannot distinguish decades, so the
  Description column is what catches a wrong-decade result.

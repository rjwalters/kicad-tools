- **`kct parts search` ranks exact resistance matches first** (Issue #9474). A
  query carrying a unit-bearing resistance (`8.2Ω`, `4k7`, `10k`, `2.2 ohm`) now
  re-ranks the returned page so parts of that nominal precede other decades
  (e.g. `820kΩ` no longer outranks `8.2Ω`); parts with unparseable values are
  kept after exact matches. The table and text output now show the part
  description so the decade is visible.

- **Trombone bumps can have chamfered 45-degree corners, and the skew tuner
  uses them for an honest plain-copper fallback** (Issue #7546). The new
  `SerpentineConfig.corner_chamfer_widths` option puts a 45-degree chamfer
  of that many trace widths at each loop corner, sized with the tuners' own
  loop-length model. Measured on pinned kicad-cli 10.0.6 with 0.1, 0.2 and
  0.3 mm traces, kct and KiCad report the same uncoupled length for a plain
  bump once the chamfer is at least half a trace width. Square bumps read
  lower in kct, which couples their flat tops where KiCad does not. With an
  uncoupled limit set, `tune_diff_pair_skew` still tries every placement as
  a square tuning pattern first. Only when all of them fail does it retry
  the same placements as plain copper with 0.55-width chamfers and at least
  one trace width of amplitude, and it commits one only if that figure
  passes. On thin traces this tunes pairs that were refused before (0.127
  mm, skew 0.5 mm, limit 0.8 mm: 0.78 mm in both engines). The
  06b/06rf/07rf benches are unchanged.

- **Board 09's `check_design.py` and `generate_design.py` refuse a non-pinned KiCad** (Issue #9495). Both producers called a bare `kicad-cli` / the host's footprint library, so committed evidence carried whatever release the host had (`10.0.8` was recorded against the `10.0.6` pin). They now run under `run_on_evidence_toolchain` like `scripts/boards/*.py`: a mismatched kicad-cli exits 2 with `REFUSED (KiCad environment, Issue #6962)` and writes nothing. `KCT_KICAD_DOCKER=1` runs `kicad-cli` on the pinned image, threads the image-qualified executable into the ERC/DRC calls (even when it is outside `PATH`), and sources `generate_design.py`'s host-side footprint reads from the image's libraries so a host library cannot leak its geometry into the board. Committed board 09 output is not regenerated here.

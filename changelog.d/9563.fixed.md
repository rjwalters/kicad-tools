- **`kct pcb sync-netlist` reports value and footprint drift on matched
  references** (Issue #9563). Matched refs are now compared for value and
  footprint lib ID using the same equivalence rules as `kct validate --sync`:
  value differences are written to the board (reported as
  "Value updates (N)"), footprint differences are reported as
  "Footprint changes (N)" with a pointer to `kct sync --apply` and make the
  command exit non-zero while unapplied. Nickname-only footprint differences
  and equivalent values (case, whitespace, SI magnitude, `~`/empty) are not
  flagged; the "PCB is in sync" message no longer prints while a footprint
  difference exists.

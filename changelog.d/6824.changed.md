- **Lattice router honours a net class's `preferred_layers`** (Issue #6824).
  Planar copper on a non-preferred layer pays a soft surcharge, and a class
  that names a plane-reserved layer (`--reserve-plane-layers`) is allowed onto
  it for its own nets. `--matrix` layer assignment no longer overwrites an
  authored `preferred_layers`. Board 03 prefers In2.Cu for USB_D. Classes with
  no preference route unchanged.

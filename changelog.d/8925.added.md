- **`tht_smd_spacing` pairs an anchor via against an exposed via annulus**
  (Issue #8925). JLCDFM's "THT to SMD" category also counts a small exposed
  via pad as the SMD side (#8914 item 5: a 1.3 mm-drill anchor via 1.5 mm from
  a 0.4 mm-drill via). A via drilled at least 1.0 mm is now judged against any
  via annulus left untented on an outer face, with the existing 2.0 mm error /
  2.7 mm warning bands; THT component pads are not paired with via annuli,
  tented annuli are skipped, and each pair is reported once. Fab-view only
  (`--mfr jlcpcb`); counts on boards 03 / 05 / 06 / 07 are unchanged.

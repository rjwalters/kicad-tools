- **`kct route` honours the board's conditional `.kicad_dru` clearance rules
  and footprint-scoped exemptions** (Issue #9578). A board whose
  `.kicad_dru` carries net-class clearance rules (e.g.
  `A.NetClass == 'HV'`) had them ignored when resolving the run's trace and
  via clearances, so newly committed vias and tracks could sit below the
  requirement `kicad-cli pcb drc` enforces; the strictest conditional
  clearance minimum now floors both resolutions (new provenance
  `project-dru-conditional`, `(severity ignore)` rules excluded). The
  kept-copper audit judges preserved copper the way KiCad resolves it:
  `A.memberOfFootprint('REF')` conditions are evaluated against the pad's
  footprint (wildcards, either pair order), so a DRC-clean input is no
  longer refused with exit 8 next to fine-pitch parts; a pair whose verdict
  hinges on a rule the evaluator cannot decide (e.g. `insideArea`) is
  reported as UNKNOWN, naming the rule, and never counted as an input
  defect.

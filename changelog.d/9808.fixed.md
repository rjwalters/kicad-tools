- **`kct zones relieve` works from the unified CLI** (Issue #9808). The repair
  command that `zones fill` warnings and the tapeout docs point users at was
  rejected by `kct` with `invalid choice: 'relieve'`; the unified parser now
  registers it with the same `pcb`, `-o/--output`, `--format` and quiet flags
  as the standalone `zones_cmd` entry, accepts `-q` both before and after the
  command, and forwards the handler's exit status.

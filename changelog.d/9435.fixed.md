- **`silk_ref_obscured` no longer reports designators hidden on purpose** (Issue #9435). A hidden
  Reference is skipped when a visible board silkscreen text on the same side is centred inside the
  footprint's courtyard (e.g. a "PWR" function label on an LED), so readiness no longer needs a
  blanket `--ack-warnings silk_ref_obscured`. Hidden references with no replacement text, and
  visible references inside their own courtyard, are still flagged.

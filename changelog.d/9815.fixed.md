- **`kct pcb reinforce` keeps wire end holes out of courtyards** (Issue #9815).
  End-anchor candidates are now tested with the same hole-vs-courtyard
  geometry `kct check` uses for `wire_run_courtyard_overlap` (pad annulus plus
  fillet clearance, courtyards on both sides, the terminating part exempt), so
  an end hole under an opposite-side part is refused as `anchor_courtyard`,
  naming the footprint, and the anchor slides inward within `--max-end-shift`.
  If no position clears, the leg is reported `partial` instead of anchored in
  the courtyard. JSON `refused` entries gain `obstacle_footprint` /
  `obstacle_side`.

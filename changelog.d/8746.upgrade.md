- **`kct check` can newly report `reinforcement_incomplete`** (Issue #8746). Boards with a `reinforcement_eligible` current path now get warnings for unreinforced or incomplete legs, and errors where an `ampacity`/`path_ampacity` waiver reason matches `reinforc|buttress|wire`. Run `kct pcb reinforce` (ends mode) or skip with `--skip reinforcement_incomplete`.

- **`kct pcb sync-netlist` no longer strips the leading `/` from root-sheet label nets and disconnecting routed KiCad-native boards** (Issue #9562). `kicad-cli sch export netlist` writes root-sheet local label nets as `/NAME`; the unconditional strip renamed almost every pad of a board whose copper still carried the `/` names, silently splitting nets (exit 0, DRC went from 0 to 267 violations on the reporter's board). Net names are now resolved against the board's own net table: the exact `/NAME` is kept when the board has it, the bare `NAME` is used when the board stores bare names (kct-generated boards keep the old behaviour), and nets new to the board follow the board's dominant convention. Syncing an unchanged schematic onto its own board now yields zero net updates under either convention. When pads move to a net name that no track, via or zone uses while the former name still has copper, the command emits a warning naming both names and the stranded copper count instead of leaving the split unnoticed.

- **`kct route` no longer loses the `_partial` board on the clean exit-8
  path** (Issue #9579). The partial save re-ran copper cleanup after the
  routing grid's per-cell arrays had been freed (#4292); when a kept trace's
  acute bend had survived finalization, that re-run indexed the freed planes
  and both serialisation attempts died with `IndexError: index 0 is out of
  bounds for axis 0 with size 0` before any board was written. The save now
  serializes the already-finalized copper without querying the grid (the
  live interrupt path keeps full cleanup). The closing statistics summary is
  non-fatal (an unavailable one is reported as such), and a genuine save
  failure names the step it failed in, e.g. `Error saving partial results
  while writing the access-witness sidecar: IndexError: ...`. Exit code and
  banner are unchanged.

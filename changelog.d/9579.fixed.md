- **`kct route` no longer reports a finished partial save as failed** (Issue
  #9579). On the `--complete` exit-8 path the routed `_partial` board and its
  sidecars were written, and then a failure computing the closing statistics
  printed `Error saving partial results: index 0 is out of bounds for axis 0
  with size 0`. The statistics are now a non-fatal summary (an unavailable one
  is reported as such), and a genuine save failure names the step it failed in,
  e.g. `Error saving partial results while writing the access-witness
  sidecar: IndexError: ...`. Exit code and banner are unchanged.

- **Current-path loop witnesses are quoted at their sheet position** (Issue #8928). On a board whose origin is not `(0, 0)`, the `[witness: ...]` / `[blocking branches: ...]` text of an ambiguous current path quoted board-relative coordinates that cannot be found in the KiCad GUI. That text appears in the `reinforcement_incomplete` `[skipped]` and `path_ampacity` ambiguous-path messages, in `kct pcb reinforce` (`unresolved_paths[].reason` in `--format json`, the stderr warning and the text report), and in `kct pcb current-paths-audit`. All of them now quote sheet-absolute coordinates. `current-paths-audit`'s JSON `witness.blocking_branches` is now sheet-absolute too, matching the rest of that `witness` dict. Witness coordinates are now always printed to 3 decimals, e.g. `(118.500, 113.000)` where the old text was `(70.0, 58.0)`. Scripts that parse the `reason` string will see this change. `PathResolution.reason` no longer contains any coordinates; render the witness with the new `kicad_tools.router.current_paths.describe_witness(witness, origin)`. `pcb prune`'s `uncut_loops[].segments` stays board-relative, like the rest of prune's report.
